# ForumTickets 论坛票务系统

学术论坛在线购票与管理平台，支持多票种、多参会人、多支付方式，附带完整后台管理功能。

---

## 功能概览

### 前台（用户端）

- **票种展示**：首页展示可购票种、价格、剩余名额
- **多人报名**：单次订单最多 5 名参会人，每人可选不同票种
- **多种支付**：支持银行转账、微信支付、支付宝（管理员后台可配置开关）
- **订单确认**：支付后自动发送确认邮件，含参会人信息及会议详情
- **PDF 导出**：成功页可导出订单确认 PDF
- **中英双语**：界面支持中文/英文切换
- **嵌入模式**：所有页面提供 `/embed/` 路由前缀，可作为 iframe 嵌入第三方网站

### 后台（管理员端）

- **票种管理**：新增/编辑/删除票种，设置名称、价格（CNY/USD）、配额、排序
- **订单管理**：查看所有订单、手动核验银行转账、按状态筛选、导出、分页（20/50/100条）、删除
- **管理员管理**：新增/停用管理员账号，角色分 `super_admin` 和 `admin`
- **赞助商管理**：维护赞助商信息（名称、Logo、分类、官网链接），首页自动展示
- **会议信息管理**：编辑会议名称、副标题、日期、地点、联系邮箱，支持多个会议切换激活
- **首页内容管理**：编辑首页标题、描述、按钮文字等文案，无需改代码
- **支付设置**：配置可用支付方式及银行转账收款信息

## 用户购票流程

```
首页浏览票种
    ↓
点击购票 → 填写参会人信息（姓名、邮箱等）
    ↓
提交订单（状态：待支付）
    ↓
选择支付方式 → 完成支付
    ↓
管理员核验（银行转账需手动确认）→ 标记为已支付
    ↓
系统自动发送确认邮件 → 用户下载 PDF 票据
```

## 管理员操作说明

### 登录

访问 `/admin/login`，使用管理员账号密码登录。

### 核验银行转账订单

1. 进入**订单管理**
2. 找到状态为"待支付"的订单
3. 确认收款后，点击"标记已支付"，输入付款方银行账号后 4 位
4. 系统自动发送确认邮件给买家

### 添加票种

1. 进入**票种管理** → 点击新增
2. 填写名称（中/英）、价格、货币（CNY/USD）、配额（-1 表示不限）
3. 保存后立即在前台生效

### 管理赞助商

1. 进入**赞助商管理** → 新增赞助商
2. 填写名称、缩写、分类、Logo URL、官网
3. 首页按分类和排序自动展示

## 嵌入第三方网站（iframe）

将以下路径的 `embed` 版本嵌入其他网站：

| 页面 | 普通路由 | 嵌入路由 |
|------|----------|----------|
| 票种列表 | `/` | `/embed/tickets` |
| 报名表单 | `/order` | `/embed/order` |
| 支付页 | `/payment/:orderNo` | `/embed/payment/:orderNo` |
| 成功页 | `/order/success/:orderNo` | `/embed/order/success/:orderNo` |

示例：
```html
<iframe src="https://your-domain.zeabur.app/embed/tickets" width="100%" height="600"></iframe>
```

## 本地开发

### 前置要求

- Node.js 18–22
- pnpm 8+

### 启动

```bash
pnpm install
pnpm dev
```

- 前端：http://localhost:5173
- 后端 API：http://localhost:3000

### 初始化数据库

```bash
pnpm db:init
```

### 环境变量

在 `packages/server/` 下创建 `.env` 文件：

```env
JWT_SECRET=your-secret-key
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your-password
EMAIL_USER=your@gmail.com
EMAIL_PASSWORD=gmail-app-password
```
